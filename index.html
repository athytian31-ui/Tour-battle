Réglages

Les 2 camps

« Mots pour rejoindre » : ce que les gens écrivent pour choisir leur camp (séparés par des virgules). Le nom du camp marche aussi. Le « cadeau du camp » met direct le spectateur dans ce camp.

Brancher ton LIVE TikTok

Ici, dans l'aperçu Claude, la connexion au LIVE est bloquée. Elle marche sur ta page GitHub (ton lien perso).

Pas connecté

Test : mets le pseudo d'un streamer qui est en LIVE en ce moment. Si des tuiles tombent, tout est branché. La connexion se relance toute seule si elle coupe.
